# Standalone open-source delivery

MiraBase is the standalone, self-hosted open-source backend. There is no MiraBase cloud or managed hosting offering. Developers run the software on their own computer/server or infrastructure provider, and may build their own SaaS or agent application on it.

No company account, subscription, telemetry service, license check, vendor control plane, MCP gateway or external data service is required for standalone use. Configured third-party auth/mail/object-storage dependencies remain the operator's choice.

Future placement/replication/routing/fleet work belongs to the [open-source roadmap](../../ROADMAP.md) and [platform proposals](../roadmap/platform/README.md), not to current standalone implementation. Preserve current HTTP/SDK/data/export contracts as the software evolves. Do not reduce current features to force a hosted subscription or silently change licensing.

Current distribution and actual checks: [release status](../../release/qualification.json), [known limitations](../current-product.md), [test evidence](../launch/status.md). Roadmap requirements are not claimed complete.
