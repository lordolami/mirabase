# MiraBase application demo

The 180-second 1080p film is an edited recording of actual application use, with local narration and captions. The actual dashboard and connected example frontend are labelled separately. Grant/revoke and historical file restoration use recorded real responses. Operator-only workspace authority and planned roadmap features are identified.

This is a demonstration, not full product/security/platform qualification. See [launch status](../../docs/launch/status.md), the [written submission](../submission/SUBMISSION.md) and the adjacent checksum manifest. Raw desktop recordings, runtime data and private recording logs are not included.
